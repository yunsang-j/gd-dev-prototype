메소드 관련

요약​

상황하면 안 되는 것권장 방법
커스터마이징 없이 메소드를 오버라이딩불필요한 오버라이딩 메소드를 그대로 남겨두기사용하지 않는 오버라이딩 메소드 삭제

1. 오버로딩된 메소드 삭제​

커스터마이징을 하지 않았음에도 무의식적으로 메소드를 남겨놓는 경우가 있어요.

사용되지 않는 메소드를 남겨둘 경우 성능 개선 및 기능 개선 배포 내용이 반영되지 않을 수 있으니, 불필요한 메소드는 삭제해 주세요.

잘못된 코드
namespace Component\Excel;
 
class ExcelRequest extends \Bundle\Component\Excel\ExcelRequest
{
public function saveInfoExcelRequest($arrData)
{
// 부모 메소드와 동일한 내용 (즉, 커스터마이징을 하지 않은 경우)
}
}
올바른 코드
namespace Component\Excel;
 
class ExcelRequest extends \Bundle\Component\Excel\ExcelRequest
{
// 불필요한 오버라이딩 메소드 삭제
}
왜 문제가 되나요?

불필요한 오버라이딩 메소드를 남겨두면, 고도몰 업데이트 시 해당 메소드의 성능 개선 및 기능 개선 내용이 반영되지 않을 수 있어요.

커스터마이징하지 않는 메소드는 반드시 삭제해 주세요.

이 문서가 도움이 되었나요?
