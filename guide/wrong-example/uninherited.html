상속 처리가 되지 않은 케이스

1. class와 method 미상속​

고도몰 개발자 코멘트: method의 경우 상속받은 형태로 구현이 불가능한 상황이 있을 수 있어요.

그렇기 때문에 가능한 한 해당 method의 상속이 가능한 상황으로 구현하시는 것이 좋아요.

잘못된 코드
namespace Component\Excel;
 
class ExcelRequest extends \Bundle\Component\Excel\ExcelRequest
{
public function saveInfoExcelRequest($arrData)
{
# write your code
}
}
올바른 코드
namespace Component\Excel;
 
class ExcelRequest extends \Bundle\Component\Excel\ExcelRequest
{
public function saveInfoExcelRequest($arrData)
{
parent::saveInfoExcelRequest($arrData);
 
# write your code
}
}
왜 문제가 되나요?

parent::saveInfoExcelRequest($arrData); 호출 없이 method를 재정의하면, 시스템 원본 method의 로직이 실행되지 않아요.

반드시 parent method를 먼저 호출해 상속 구조를 유지한 뒤에 커스터마이징 코드를 추가해 주세요.

2. system의 controller 커스터마이징 시 class 미상속​

고도몰 개발자 코멘트: 아래 잘못된 코드 예시는 class와 method의 상속을 받지 않고 구현된 내용이에요.

잘못된 코드
namespace Controller\Admin\Goods;
 
/**
* 상품 리스트 페이지
*/
class GoodsListController
{
# write your code
}
올바른 코드
namespace Controller\Admin\Goods;
 
/**
* 상품 리스트 페이지
*/
class GoodsListController extends \Bundle\Controller\Admin\Goods\GoodsListController
{
parent::index();
 
# write your code
}
왜 문제가 되나요?

class와 method를 상속하지 않으면 시스템 controller의 기능을 이어받지 못해요.

반드시 \Bundle\Controller\Admin\Goods\GoodsListController를 사용해서 시스템의 GoodsListController를 상속받아야 해요.

또한 method 안에서는 parent::index();를 사용해서 시스템의 index()를 상속받아야 해요.

이 문서가 도움이 되었나요?
