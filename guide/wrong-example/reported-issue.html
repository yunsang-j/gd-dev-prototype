1. 마스터 DB Query 과다 사용으로 인한 서버 부하​

커스터마이징 시 부하가 많이 발생할 것 같은 Query문에는 반드시 slave 메소드 처리를 해주세요.

slave 사용 방법

  • Slave DB가 존재하는 상점에서만 사용할 수 있어요.
  • 동적으로 DB 값이 변경되는 쿼리는 사용하지 마세요.
  • 정적인 값을 보유한 쿼리의 경우:
    • master: $this->db->query_fetch()
    • slave: $this->db->slave()->query_fetch()
  • slave 메소드 미지원 시 자동으로 master로 전환돼요.
  • 활용 예시:
    • 페이징 처리를 위한 count 쿼리
    • 실시간으로 update된 데이터를 보여줄 필요가 없는 쿼리
    • 기타 설정을 저장하는 쿼리

2. 분산서버를 고려하지 않고 기능을 만든 경우​

분산서버 사용 시 분산서버를 고려하여 개발해야 해요.

잘못된 예시처럼 로컬 스토리지에 직접 파일을 업로드하면 분산서버 환경에서 파일 접근이 불가능할 수 있어요.

PHP
// 하면 안 되는 예시
Storage::disk(Storage::SOME_PATH, 'local')->upload($tmpFileNm, $newFileNm);

권장하는 처리 방법은 다음과 같아요.

  1. 고도몰의 게시판 첨부파일 저장 코드를 확인하여, 분산서버 사용 시 원본 서버에 파일이 저장되도록 수정
  2. 원본 서버의 API 도메인에 파일을 업로드하는 API를 만들어, 해당 API로 파일을 전송하여 원본 서버에만 저장
  3. 기타 방법으로 첨부파일이 분산서버가 아닌 원본 서버나 다른 서버에 저장되도록 변경

3. 고도몰이 정의한 DB의 값을 임의의 값으로 변경하는 경우​

고도몰이 정의한 DB 컬럼의 값을 임의로 변경하는 경우, 고객 상점에서만 사용할 수 있는 문구로 수정해 주세요.

잘못된 코드
adminMenuNo = 'godo008***'
올바른 코드
# test가 아닌 임의의 4자리 문자열로 변경 필요
adminMenuNo = 'test******'

4. 모든 영향 범위에 커스터마이징 내용을 적용하지 않은 경우​

새로운 값의 정의를 추가하는 경우, 관련 범위의 파일도 모두 수정해 주세요.

잘못된 코드
<!--{ ? req.bdId == 'useras' }-->
<form id="asWrite" action="../board/board_ps.php" method="post" enctype="multipart/form-data" class="frmWrite">
<!--{ : }-->
<form name="frmWrite" id="frmWrite" action="../board/board_ps.php" method="post" enctype="multipart/form-data" class="frmWrite">
<!--{ / }-->
올바른 코드
<form name="frmWrite" id="frmWrite" action="../board/board_ps.php" method="post" enctype="multipart/form-data" class="frmWrite">

5. DB에 이미지 바이너리 데이터를 넣은 경우​

DB에 이미지 바이너리 데이터를 저장하면 안 돼요

고도몰 DB에는 이미지 바이너리 데이터를 저장해서는 안 돼요.

부하 발생 시 상점 차단과 같은 불이익이 발생할 수 있어요. 특히 공용서버의 경우 다른 상점도 영향을 받을 수 있어요.

DB 테이블 컬럼에 이미지 바이너리 데이터를 절대로 넣지 마세요.

잘못된 예시처럼 base64 인코딩된 이미지 데이터를 DB에 직접 저장하지 마세요.

6. NOT NULL 필드 추가 시 기본값 설정 필수​

데이터 무결성 오류 주의

Table의 새로운 필드를 NOT NULL로 추가할 경우, 기존 데이터에 대해 기본값을 설정하지 않으면 데이터 무결성 오류가 발생할 수 있어요.

필드 정의 시 DEFAULT 키워드를 사용하여 기본값을 지정해요.

SQL
ALTER TABLE your_table ADD COLUMN new_column VARCHAR(255) NOT NULL DEFAULT 'default_value';
