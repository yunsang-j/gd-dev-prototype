에이전시 작업 전 체크리스트

왜 필요한가요​

에이전시에 개발을 맡길 때, 사전에 확인해 두지 않으면 작업 후 문제가 생겼을 때 원인 추적이 어려워져요.

작업 시작 전에 아래 항목을 확인해 두면 소통과 문제 해결에 도움이 돼요.

작업 의뢰 전 확인 항목​

확인 항목왜 필요한가요
개발소스관리 기능이 켜져 있나요?변경 이력 기록과 복원 기능을 사용하려면 기능이 활성화되어 있어야 해요.
스테이징 환경이 준비되어 있나요?운영에 반영하기 전에 스테이징에서 먼저 확인하는 절차가 필요해요.
작업 전 소스 상태를 저장해 두었나요?작업 중 문제가 생겼을 때 이전 상태로 되돌릴 기준이 있어야 해요.
작업 범위를 문서로 전달했나요?어떤 기능을 어디까지 개발할지 명확히 해두면 의도치 않은 변경을 줄일 수 있어요.
배포 일정과 확인 담당자를 정해 두었나요?스테이징 확인과 최종 반영 시점을 운영자가 알고 있어야 해요.
주의

개발소스관리 기능 활성화 여부와 스테이징 환경 구성은 에이전시 또는 개발 담당자가 진행해요.

확인이 필요하면 에이전시에 먼저 문의해 보세요.

에이전시에 전달할 정보 목록​

작업을 의뢰할 때 아래 정보를 함께 전달하면 에이전시가 고도몰 가이드에 맞게 작업하는 데 도움이 돼요.

  • 고도몰 버전 및 PHP 버전 (관리자 화면에서 확인 가능)
  • 상점 URL (스테이징 URL 포함)
  • 커스터마이징할 기능의 범위와 목표
  • 배포 일정 및 확인 방법
안내

에이전시에 커스터마이징 가이드 링크를 전달하면, 고도몰 커스터마이징 규칙과 주의사항을 미리 확인하고 작업을 시작할 수 있어요.
