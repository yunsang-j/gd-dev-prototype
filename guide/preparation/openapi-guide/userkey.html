인증키 발급 방법 안내

오픈 API를 통한 연동 개발에 앞서 꼭 필요한 인증키 발급 방법을 안내해요.

이용 중인 쇼핑몰에서 자체 개발하거나 귀사에서 제공 중인 서비스와 고도몰 서비스의 연동 개발을 진행하는 경우에 필요한 정보예요.

타사 서비스를 이용하는 경우 샵링커, 이지어드민, 셀메이트 등에 해당한다면 서비스 제공사에 문의해 주세요.

플레이오토의 경우 바로 사용자키 신청해 주세요.

연동 개발에 이용되는 인증키는 총 2개로 제휴사 키와 사용자 키가 있어요.

제휴사 키​

제휴사 키는 실제 개발을 진행하는 곳에 발급되는 인증키예요.

  • 자체 개발의 경우 최초 1회에 한하여 오픈 API 개발자 등록 메뉴에서 신청해요.
  • 연동 개발사를 이용하는 경우 해당 개발사에 고도 서비스 이용 가능 여부를 문의해요. (플레이오토, 샵링커, 이지어드민, 셀메이트 등은 현재 개발사 등록이 돼 있어요.)

자체 개발 또는 연동 개발사가 개발자 등록을 완료하면 담당자 확인 후 승인 처리되며, 등록 시점에 사용한 회원 계정으로 마이페이지에서 사용자키 신청 URL을 확인할 수 있어요.

사용자 키​

사용자 키는 제휴사 키와 쇼핑몰에 매칭되는 고유 인증키예요.

  • 각 제휴사에 맞춰 생성된 사용자키 신청 URL에서 연동할 쇼핑몰을 선택해요. (해당 쇼핑몰을 보유한 고도 회원 아이디와 쇼핑몰 도메인을 알고 있어야 해요.)
  • 신청 후 해당 쇼핑몰을 보유한 고도 회원 아이디 이메일 주소로 최종 확인 메일이 발송돼요.
  • 유효기간 내 메일 확인 후 사용자 인증을 완료하면 최종 신청이 완료돼요.

사용자 키 최종 신청(사용자 인증)까지 완료하면 담당자 확인 후 발급 처리되며, 개발자 등록 시점에 작성한 이메일로 키 값을 전달해요. 키 값은 개발사에만 전달되며, 쇼핑몰 보유 회원에게는 발급 완료 내역이 SMS로 전송돼요.

모든 인증키 신청은 개발자센터를 통해서만 가능하며, 이외 궁금하신 사항은 1:1 문의를 이용해 주세요.
