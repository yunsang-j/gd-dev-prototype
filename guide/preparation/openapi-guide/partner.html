공급사 이용 방법 안내

별도 추가 개발 없이 기존 오픈 API를 통해 바로 서비스 이용이 가능한 공급사 전용 인증키 발급 방법을 안내해요.

발급 절차​

  1. 개발사 등록이 돼 있는지 확인해 주세요. 개발사 등록이 돼 있어야 이후 진행이 가능해요. 오픈 API 인증키 발급 방법 안내 참고

  2. 개발사 등록이 돼 있다면 아래 순서에 맞춰 사용자키를 신청해요.

    1. 개발자센터 > 마이페이지 > 사용자키 신청 메뉴를 통해 사용자키 신청 페이지에 접속해요.
    2. 사용자 분류에서 '공급사'를 선택해요.
    3. 입점한 쇼핑몰의 대표 도메인 또는 임시 도메인과 공급사명을 입력한 후 '검색'해요.
    4. 공급사를 선택한 후 쇼핑몰 관리자에 등록된 대표 운영자 아이디를 입력해요.
    5. 모든 정보를 정상 입력한 후 '등록하기'를 실행해요.

  3. 본사와 공급사 대표 이메일로 발송된 사용자 인증 메일을 확인해 주세요.

    • 본사의 경우 고도 회원 계정에 등록된 이메일 주소로 발송돼요.
    • 공급사의 경우 쇼핑몰 관리자의 공급사 대표 운영자 정보에 등록된 이메일 주소로 발송되며, 신청 후 1주일 이내에 모든 인증이 완료돼야 해요.

  4. 담당자 확인 후 사용자키가 발급되며, 사용자 인증 메일이 발송된 동일한 이메일로 키 값이 전달돼요.

유의사항
  • 오픈 API를 통해 조회/등록/수정/삭제되는 모든 작업은 해당 공급사의 정보로만 한정돼요.
  • 기존 오픈 API를 동일하게 사용하나, 공급사의 경우 쇼핑몰 관리자 이용과 동일하게 일부 기능이 제한돼요.
  • 본사에서 공급사 등록 시 부여된 상품 승인 권한 및 기능 권한에 따라 일부 기능이 제한될 수 있어요.

모든 인증키 신청은 개발자센터를 통해서만 가능하며, 이외 궁금하신 사항은 1:1 문의를 이용해 주세요.
