HTTP 소개

Request​

사용자 요청 제어를 담당하며, $_GET, $_POST, $_FILES, $_SERVER, $_REQUEST에 접근할 수 있어요.

PHP
Request::get()->get('someKey'); // $_GET['someKey']
Request::post()->get('someKey'); // $_POST['someKey']
Request::server()->get('REQUEST_URI'); // $_SERVER['REQUEST_URI']
Request::files()->get('someKey'); // $_FILES['someKey']
Request::request()->get('someKey'); // $_REQUEST['someKey']

$_ENV는 지원하지 않으며, dot notation을 다차원 키 접근에 사용해요.

값 설정하기​

PHP
Request::get()->set('name', 'value');
Request::post()->set('name', 'value');
Request::files()->set('file.name', 'value');
Request::request()->set('sampel.name', 'value');
Request::server()->set('REQUEST_URI', 'value');

값 가져오기​

PHP
$name = Request::get()->get('name');
$name = Request::post()->get('name.first');
$name = Request::files()->get('name.first');
$name = Request::request()->get('name.first');
$name = Request::server()->get('REQUEST_URI');

요청값이 없는 경우 두 번째 인자로 기본값을 설정해요.

PHP
$name = Request::get()->get('name', '기본값');
$name = Request::post()->get('name.first', '기본값');

모든 값 가져오기​

PHP
$allGet = Request::get()->all();
$allGet = Request::get()->toArray();

값 지우기​

PHP
Request::get()->del('name');
Request::get()->del('name.first');

모든 값 지우기​

PHP
Request::get()->clear();

값의 존재 여부 체크하기​

PHP
if (Request::get()->has('name')) {
// some code...
}
 
if (Request::get()->has('name.first')) {
// some code...
}

주요 Method​

getServerAddress()​

서버의 IP 주소를 반환하며 CLI에서도 정상 작동해요.

getRemoteAddress()​

클라이언트의 IP 주소를 반환하며 Proxy나 nginx 환경에서도 정상 작동해요.

isCli()​

CLI 접근 여부를 boolean으로 반환해요.

PHP
if (Request::isCli()) {
// background process
}

isAjax()​

Ajax 요청 여부를 boolean으로 반환해요.

PHP
if (Request::isAjax()) {
// ajax code
}

isMethod($method)​

현재 REQUEST_METHOD와 지정된 메서드를 비교해요. get, post, head, options, put, delete, trace, connect 중 하나여야 해요.

PHP
if (Request::isMethod('get')) {
// get인 경우만 실행
}
 
if (Request::isMethod('post')) {
// post인 경우만 실행
}

isMobile()​

도메인에 m이 있는지 여부를 통해 모바일 여부를 boolean으로 반환해요.

PHP
if (Request::isMobile()) {
// 도메인이 m.domain.com 인 경우
}

isMobileDevice()​

UserAgent를 통해 모바일 또는 태블릿 기기 접속 여부를 boolean으로 반환해요.

PHP
if (Request::isMobileDevice()) {
// 접속 기기가 모바일/태블릿인 경우
}

isRefresh()​

브라우저 새로고침 여부를 boolean으로 반환해요.

PHP
if (Request::isRefresh()) {
// 페이지 새로고침을 한 경우
}

Response​

Json, Redirect, Streamed, BinaryFile의 4가지 응답 형태를 지원하며 Chaining method를 제공해요.

Create Instance​

PHP
$response = Response::create($content, $statusCode, $headers);

Session​

파일 세션만 지원하며, dot notation을 다차원 키 접근에 사용해요.

Setting a value​

PHP
Session::set('name', 'value');
Session::set('name.first', 'value');

Getting a value​

PHP
$name = Session::get('name');
$name = Session::get('name.first');

기본값 설정이 불가능하며, 미설정 시 null로 반환돼요.

Getting all values​

PHP
$session = Session::all();

Removing a value​

PHP
Session::del('name');
Session::del('name.first');

Removing all values​

PHP
Session::clear();

Determining if an given key exists​

PHP
if (Session::has('name')) {
// some code...
}
 
if (Session::has('name.first')) {
// some code...
}

Cookie​

쿠키는 다차원 키를 사용할 수 없어요.

Setting a value​

PHP
Cookie::set('name', 'value'); // 세션 쿠키 생성
Cookie::set('name', 'value', 3600, '/', true, true); // 1시간 만료 쿠키 생성

Getting a value​

PHP
$name = Cookie::get('name');

Getting all values​

PHP
$session = Cookie::all();

Removing a value​

PHP
Cookie::del('name');

Determining if an given key exists​

PHP
if (Cookie::has('name')) {
// some code...
}
