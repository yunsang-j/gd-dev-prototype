Controller 제공 메소드​

download​

PHP
download($path, $newFile)

$path의 파일을 $newFile이라는 이름으로 다운로드해요.

json​

PHP
json($data)

$data가 비어 있는 경우 Controller 내 data를 json으로 변경하고, $data가 있는 경우 json을 출력한 뒤 exit 처리돼요.

streamedDownload​

PHP
streamedDownload($path)

$path로 index()에 출력하는 모든 버퍼를 파일로 저장해요.

redirect​

PHP
redirect($uri, $title = null, $target = 'self')

페이지를 특정 URI로 이동시켜요.

일반적으로 동일한 프레임에서 작동하며, iframe이 타겟인 경우에는 사용하시면 안 돼요.

alert​

PHP
alert($message, $history = null, $url = null, $target = null, $addScript = null)

Alert 창을 출력하며, 출력 후 exit 처리돼요.

js​

PHP
js($script)

$script 텍스트로 사용자 정의 스크립트를 작성할 수 있어요.

layer​

PHP
layer($message = null, $addScript = null, $timeOut = 3000)

관리자 컨트롤러에서만 사용할 수 있어요.

레이어를 출력할 수 있으며, 레이어 출력 이후 레이어를 닫으면 페이지가 새로고침돼요.

layerNotReload​

PHP
layerNotReload($message = null, $addScript = null, $timeOut = 2000)

관리자 컨트롤러에서만 사용할 수 있어요.

레이어를 출력할 수 있으며, 레이어 출력 이후 레이어를 닫아도 페이지가 새로고침되지 않아요.

addMeta​

PHP
addMeta(array $metaTags)

스킨의 헤더에 메타태그를 추가할 수 있어요.

front와 mobile에서만 사용 가능하며, admin에서는 사용할 수 없어요.

addCss​

PHP
addCss(array $styles, $isShare = false)

스타일시트의 경로를 배열로 받아서 스킨 상단에 출력해요.

$isShare를 true로 하는 경우 /data/assets에 있는 공유 리소스를 사용할 수 있어요.

addScript​

PHP
addScript(array $scripts, $isShare = false, $isFooter = false)

스크립트의 경로를 Array로 받아서 스킨 상/하단에 출력해요. (예: ['common.js', 'common2.js'])

  • 경로는 /data/[skin path]/js에 있는 공유 리소스를 사용할 수 있어요.
  • $isShare를 true로 하는 경우 /data/assets에 있는 공유 리소스를 사용할 수 있어요.
  • $isFooter를 true로 하는 경우 스킨 내 {footerScript} 치환코드로 반환해요.
  • false인 경우 스킨 내 {headerScript} 치환코드로 반환해요.

callMenu​

PHP
callMenu($topMenu, $midMenu, $thisMenu)

관리자 메뉴 데이터를 생성해요.

관리자 메뉴를 새로 추가할 경우, 추가할 메뉴 페이지에 해당하는 컨트롤러 내에서 해당 함수를 호출해요.

es_adminMenu 테이블에 추가할 메뉴 데이터를 insert한 후에 1차 메뉴($topMenu), 2차 메뉴($midMenu), 3차 메뉴($thisMenu) 파라미터대로 메소드를 호출해요.

사용자 정의 Controller 기본 메소드​

고도몰에서는 기본적으로 3개의 사용자 정의 Method를 제공해요.

Method 종류

  1. pre(): 시스템 전 처리기 interceptor의 실행 직전에 실행돼요.
  2. index(): 사용자가 처리할 내용을 작성할 수 있어요.
  3. post(): 시스템 후 처리기 interceptor의 실행 직후에 실행돼요.
PHP
<?php
namespace Controller\Front\Test
 
class MyController extends \Controller\Front\Controller
{
public function pre()
{
// interceptor 실행 이전 실행할 로직 구현
}
public function index()
{
// 사용자 정의 로직 구현
}
public function post()
{
// interceptor 실행 이후 실행할 로직 구현
}
}

전역으로 사용할 수 있는 사용자 정의 Controller​

모든 페이지에 공통으로 적용할 수 있는 사용자 정의 컨트롤러를 생성할 수 있어요.

프론트는 module\Controller\Front 경로에 CommonController 클래스를 생성해요.

PHP
<?php
namespace Controller\Front;
 
/**
* 사용자들이 모든 컨트롤러에 공통으로 사용할 수 있는 컨트롤러 Class
* 컨트롤러에서 지원하는 메소드들을 사용할 수 있습니다.
*/
class CommonController
{
public function index($controller)
{
/**
* IP를 추가합니다.
* 스킨에서 {=remoteAddr} 치환코드로 사용 가능합니다.
*/
$controller->setData('remoteAddr',\Request::server()->get('REMOTE_ADDR'));
/**
* 새 변수를 추가합니다.
* 스킨에서 {=userName} 치환코드로 사용 가능합니다.
*/
$controller->setData('userName', '사용자 이름');
}
}

모바일은 module\Controller\Mobile 경로에 CommonController 클래스를 생성해요.

PHP
<?php
namespace Controller\Mobile;
 
/**
* 사용자들이 모든 컨트롤러에 공통으로 사용할 수 있는 컨트롤러 Class
* 컨트롤러에서 지원하는 메소드들을 사용할 수 있습니다.
*/
class CommonController
{
public function index($controller)
{
/**
* IP를 추가합니다.
* 스킨에서 {=remoteAddr} 치환코드로 사용 가능합니다.
*/
$controller->setData('remoteAddr',\Request::server()->get('REMOTE_ADDR'));
/**
* 새 변수를 추가합니다.
* 스킨에서 {=userName} 치환코드로 사용 가능합니다.
*/
$controller->setData('userName', '사용자 이름');
}
}

Api 사용자 정의 Controller​

Api 통신이 가능한 사용자 정의 컨트롤러를 생성할 수 있어요.

module/Controller/Api 경로에서 사용하시면 돼요.

만약 디렉토리가 없다면 생성한 뒤 chmod 707로 권한을 변경해야 해요.

Front/Mobile 커스터마이징과 동일한 방법으로 Controller를 생성해요.

생성 예시

  • 경로: module/Controller/Api/Load/GetApiController.php
  • 링크: api.{상점도메인}/load/get_api
PHP
<?php
namespace Controller\Api\Load;
 
class GetApiController extends \Controller\Api\Controller
{
public function index()
{
// some code ...
}
}
멀티서버 환경에서의 호출 방법

멀티서버(이벤트 서버) 환경에서 외부 cron 호출, 자동결제 등 서버 간 상태 공유가 필요한 기능은 반드시 api.{도메인}을 통해 호출해야 해요.

자세한 내용은 분산 환경 개발 가이드 문서를 참고해 주세요.
