커스터마이징 방법

테이블 생성​

Engine 타입​

테이블 생성 시 InnoDB 엔진을 반드시 사용해야 해요. 다른 타입을 사용하면 테이블 손상 등의 문제가 발생할 수 있어요.

Character set, Collation​

  • Character set: utf8mb4
  • Collation: utf8mb4_general_ci

솔루션 기본값과 다르게 사용하면 조인 에러가 발생해요. (Error Code: 1267. Illegal mix of collations)

Primary key​

InnoDB 엔진에서 정렬 및 저장 기준으로 사용되므로 반드시 생성해야 해요.

Comment​

테이블 및 컬럼 추가 시 용도 파악을 위해 반드시 작성해야 해요.

Prefix​

솔루션 자동 패치 시 중복을 방지하기 위해 테이블 및 컬럼 생성 시 접두사를 반드시 사용해야 해요. es_, zz_는 솔루션 예약 접두사이므로 사용할 수 없어요.

솔루션 제공 기본 데이터​

Table, Column

  • 솔루션 기본 테이블 및 컬럼명은 수정/삭제를 금지해요.
  • 수정 시 사이트 오류가 발생해요.

Column Data Type

  • 기본 제공 컬럼의 데이터 타입 수정을 금지해요. 자동 패치 시 원복돼요.
  • 필요하면 새 컬럼을 추가하여 사용해요.

ENUM Type

  • 기본 제공 ENUM 컬럼에 값 추가를 금지해요. 미정의 값으로 처리되어 오동작이 발생할 수 있어요.
  • 상태값 확장이 필요하면 별도 컬럼을 추가해요.

컬럼 생성​

Default Value​

NotNull 컬럼에는 기본값을 반드시 지정해야 해요. 미설정 시 데이터 무결성 오류가 발생할 수 있어요.

Comment​

컬럼 추가 시 용도 파악을 위해 반드시 작성해야 해요.

쿼리 작성​

문자형, 숫자형 데이터 타입 주의​

데이터 타입에 맞는 올바른 쿼리를 작성해야 해요. 문자형은 ''을 사용해야 하며, 인덱스 컬럼의 경우 타입이 불일치하면 인덱스를 사용하지 않아요.

SQL
-- 숫자형
WHERE goodsNo = 123456
 
-- 문자형
WHERE orderNo = '123456'

SELECT 절 '*' 사용 자제​

필요한 컬럼만 명시해요. 불필요한 데이터 반환으로 쿼리 속도가 저하될 수 있어요.

SQL
SELECT orderNo, mallSno, memNo ...

WHERE 절 조회 조건 추가​

WHERE 절은 반드시 포함해야 해요. 조건이 없으면 전체 테이블을 조회하여 성능이 저하돼요.

SQL
WHERE orderNo = '20240415001010'

JOIN, GROUP BY, ORDER BY​

불필요한 구문 사용을 지양해요.

불필요한 JOIN 예:

SQL
-- es_orderGoods 컬럼을 사용하지 않는 경우
SELECT a.orderNo, a.mallSno, a.memNo
FROM es_order AS a
LEFT JOIN es_orderGoods AS b
ON b.sno = a.sno
WHERE a.order_no = '20240415001010'

불필요한 GROUP BY 예:

SQL
-- 집계함수 없이 GROUP BY를 사용하는 경우
SELECT orderNo, mallSno
FROM es_order
WHERE orderStatus = 'o1'
GROUP BY orderNo, mallSno

조건 컬럼 가공 대신 상수 부분 가공​

좌변 컬럼을 변형하면 인덱스를 사용하지 않아요.

SQL
-- 인덱스 사용 불가
WHERE SUBSTR(orderStatus, 1, 1) = 'o'
 
-- 인덱스 사용 가능
WHERE orderStatus like 'o%'

솔루션 수정​

DBTableField​

DBTableField는 고도몰 솔루션의 모든 Table과 Column을 정의한 클래스로, 자동으로 테이블과 컬럼을 불러와 사용할 수 있게 해요.

원본 소스 위치: Bundle/Component/Database/DBTableField.php

Table, Column 추가 방법​

사용자 소스의 module/Component/Database 폴더에 DBTableField.php를 생성하고, 원본 소스 Component를 상속하여 확장해요.

PHP
<?php
namespace Component\Database;
class DBTableField extends \Bundle\Component\Database\DBTableField
{
public static function methodName()
{
// some code ...
}
}

Table 추가​

메서드명은 table + es_를 뺀 첫 글자 대문자인 테이블명 형식으로 지정해요.

필드 배열의 각 항목에서 사용하는 키는 아래와 같아요.

키설명
val컬럼명
typ컬럼 타입 (숫자형: i, 문자형: s)
def기본값
PHP
<?php
namespace Component\Database;
class DBTableField extends \Bundle\Component\Database\DBTableField
{
public static function tableTestTable()
{
$arrField = [
['val' => 'sno', 'typ' => 'i', 'def' => null], // 일련번호
['val' => 'testNo', 'typ' => 'i', 'def' => '1'], // 테스트 번호
['val' => 'testId', 'typ' => 's', 'def' => null], // 테스트 아이디
];
return $arrField;
}
}

Column 추가​

기존 메서드를 상속하여 부모 메서드에서 필드를 가져온 뒤 새 필드를 추가해요.

PHP
<?php
namespace Component\Database;
class DBTableField extends \Bundle\Component\Database\DBTableField
{
public static function tableGoods($conf = null)
{
// 부모 method 상속
$arrField = parent::tableGoods($conf);
 
// 추가 필드
$arrField[] = ['val' => 'testNo', 'typ' => 'i', 'def' => '1']; // 테스트 번호
$arrField[] = ['val' => 'testId', 'typ' => 's', 'def' => null]; // 테스트 아이디
 
// 필드값 리턴
return $arrField;
}
}
