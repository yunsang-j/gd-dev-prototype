테이블 백업​

  • 작업 전 테이블을 반드시 백업해야 해요.
  • phpMyAdmin의 export 기능을 이용하여 백업할 수 있어요.
  • 아래와 같은 형식의 백업은 가능하지만, CTAS(CREATE TABLE AS SELECT)가 실행되는 동안 Lock이 발생하여 상점 운영에 영향을 줄 수 있고 용량 이슈로 서버 부하가 발생할 수 있어요. 가급적 export 기능을 사용하는 것을 권장해요.
SQL
CREATE TABLE backup_es_order LIKE es_order;
INSERT INTO backup_es_order SELECT orderNo, mallSno, ... FROM es_order WHERE orderNo ...

오브젝트 이름에 키워드 및 예약어 사용 금지​

  • MySQL에 내재되어 있는 예약어 사용을 금지해요.
  • ` (백틱)으로 이름을 감싸서 사용하면 강제로 생성되므로 백틱 사용을 금지해요.
SQL
-- 예약어를 백틱으로 감싸면 생성 성공
CREATE TABLE reserved_word (
`rank` int not null,
PRIMARY KEY (`rank`)
);
 
-- 예약어를 그냥 사용하면 에러메시지 발생
CREATE TABLE reserved_word (
rank int not null,
PRIMARY KEY (rank)
)

)' at line 3

오브젝트 이름에 특수문자 사용 금지​

사용 가능한 문자는 아래와 같아요.

  • 숫자: 0-9
  • 영문: a-z, A-Z
  • 특수문자: $, _

` (백틱)으로 감싸면 강제로 생성되므로 사용을 금지해요. 특수문자를 사용하면 보안 패치, 업그레이드 등에서 제외될 수 있어요.

개발 시 유의사항​

경고

개발 가이드를 준수하지 않아 발생하는 모든 문제는 전적으로 이용자에게 책임이 있어요.

접두사 사용 안 함, Table 이름/Column 명칭의 수정·삭제, Column Type 변경 등으로 인해 오류가 발생한 경우, 해당 부분에 대한 모든 책임은 직접 데이터베이스를 컨트롤한 주체에 있으며 본사(NHN커머스)에서는 책임지지 않아요.
