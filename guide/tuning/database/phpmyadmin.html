PhpMyAdmin 이용

직접 설치 제한​

  • 보안상의 이유로 2021년 9월 1일부터 phpMyAdmin 직접 설치를 제한해요.
  • phpMyAdmin을 설치한 경우 반드시 삭제해 주세요.
  • 2021년 9월 1일 이후 phpMyAdmin 서버 설치가 발견되면 NHN커머스에서 사전 안내 없이 삭제 처리해요.

접속 조건​

고도몰 pro, 고도몰 business(pro+)에서만 사용할 수 있어요. 고도몰 standard, 고도몰 basic은 제공되지 않아요.

접속 방법​

NHN커머스 마이페이지를 통해 phpMyAdmin에 접속할 수 있어요.

  • 고도몰 pro 메뉴 위치: 마이페이지 > 쇼핑몰관리 > 쇼핑몰목록 > 기본관리 탭 > DB 관리
  • 고도몰 business(pro+) 메뉴 위치: 마이페이지 > 쇼핑몰관리 > 쇼핑몰목록 > 호스팅관리 탭 > DB 관리
  1. [접속 허용 IP관리]를 클릭한 후 phpMyAdmin에 접속할 IP 정보를 접속 허용 IP로 등록해요.
  2. [phpMyAdmin 접속]을 클릭한 후 NHN커머스 로그인 비밀번호를 입력하면 phpMyAdmin 사이트가 출력돼요.
  3. phpMyAdmin 사이트에서 접속할 사용자명/암호를 입력한 후 [실행]을 클릭해요.
    • 사용자명: 접속할 쇼핑몰의 DB 아이디
    • 암호: 접속할 쇼핑몰의 DB 비밀번호
  4. phpMyAdmin 사이트에서 DB 데이터를 추가/수정/삭제할 수 있어요.

개발 시 유의사항​

경고

phpMyAdmin으로 인한 보안 사고가 발생하는 경우 모든 책임은 고객에게 있어요.

phpMyAdmin을 통해 관리(생성/수정/삭제)되는 DB 데이터에 대한 책임은 이용자에게 있어요.
