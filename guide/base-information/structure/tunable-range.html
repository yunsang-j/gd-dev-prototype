커스터마이징 가능 범위/영역​

고도몰에서 커스터마이징할 수 있는 범위와 영역은 아래와 같아요.

  • module/Controller: 컨트롤러 영역으로, 사용자 URI 요청에 1:1로 대응해요.
  • module/Controller/API: API 영역으로, URL 요청에 1:1로 대응해요.
  • module/Component: 컴포넌트 영역으로, 비즈니스 로직과 데이터 핸들링을 처리해요.
  • module/Widget: 화면 부분 요소로 추가할 수 있는 기능을 제공해요.
  • module/Asset/Admin: 관리자 스킨소스 보기 영역으로, 관리자 내의 메뉴와 페이지를 제공해요.
안내

관리자 스킨소스 보기 영역은 상속 개념이 적용되는 영역에 포함되지 않아요.

이 때문에 자동패치 적용 시 커스터마이징으로 인한 오류가 발생할 수 있어서 자동패치를 지원하지 않아요.

관리자 스킨소스 보기 영역이 패치된 경우에는 패치된 부분의 고도몰 원본 소스를 직접 반영해 주셔야 해요.

상점 기준 커스터마이징 경로​

상점 디렉터리를 기준으로 보면 커스터마이징 파일은 아래 경로에 위치해요.

구분경로
관리자 스킨{상점}/admin/*
고도몰 로직{상점}/module/*

이 경로 밖의 시스템 코어 영역은 업그레이드나 패치 시 원본 소스로 덮어써질 수 있어서 커스터마이징 대상이 아니에요.

반드시 확인해주세요​

주의
  • 패치 내용이 정상적으로 적용되지 않을 경우, 고도몰 기능이 정상 동작하지 않을 수 있어요. 자동패치를 적용받기 위한 조건을 한 번 더 확인해 주세요. 자동패치 적용 조건 확인하러 가기
  • 커스텀 개발 시 다른 클래스를 사용하는 경우에는 namespace와 class 사이에 use를 이용해 사용하려는 클래스를 추가해야 해요.
  • module 폴더 이외에서의 개발 관련 작업은 운영 정책상 삭제될 수 있어요.
