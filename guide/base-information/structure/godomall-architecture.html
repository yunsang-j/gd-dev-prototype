홈개발가이드고도몰 아키텍처

고도몰 아키텍처

Request 처리 순서​

  1. 사용자의 요청은 route로 전달되어 고도몰에서 처리할 준비를 해요.
  2. Application은 솔루션 구동에 필요한 리소스를 준비하고, 요청을 처리할 Controller를 찾아서 실행시켜요.
  3. Controller는 사용자의 Request를 처리하고, 템플릿을 찾아 화면에 보여질 데이터를 전달해요.
  4. 템플릿은 Controller로부터 데이터를 전달받아 설정한 뒤 Controller로 HTML 스트링을 반환해요.
  5. Controller는 템플릿과 데이터가 처리된 HTML 스트링을 화면에 출력해요.

Route의 동작​

  • 사용자의 요청은 모두 사용자 소스 디렉토리(User Source Directory) 안의 route.php에서 받은 뒤 처리돼요.
  • autoload.php는 ClassLoader를 이용해 원본 소스 디렉토리(Base Source Directory)와 사용자 소스 디렉토리(User Source Directory) 아래의 클래스를 생성해 로드해요.
  • bootstrap.php는 Application을 생성한 뒤 필요한 리소스를 로드해요.

Application의 동작​

  • bootstrap.php에서 Application 객체를 생성해요.
  • Application 객체가 생성되면 AbstractBootstrap을 상속받은 클래스를 로드해 객체를 모두 실행해요.
  • Bootstrap에 필요한 클래스의 객체를 생성한 뒤 Application 컨테이너에 주입해요.
  • Application의 실행 준비가 완료되면 사용자 요청을 처리할 Controller를 찾아서 요청을 처리하도록 해요.

Controller의 동작​

  • Interceptor에서 템플릿 레이아웃 설정, 글로벌 변수 설정, 통계 데이터 측정, 보안 및 인증과 같이 전역에서 이루어져야 하는 작업을 처리해요.
  • 사용자가 작성한 MyController::pre() 메소드가 실행돼요.
  • 사용자가 작성한 MyController::index() 메소드가 실행돼요.
  • 사용자가 작성한 MyController::postHandle() 메소드가 실행돼요.

View의 동작​

  • 컨트롤러에서 호출한 View 엔진인 Template_를 토대로 템플릿 엔진을 구성해요.
  • 템플릿 엔진의 종류
    1. Template_ 엔진: 사용자 스킨 처리
    2. Include 엔진: 관리자 스킨 처리

Class Loader​

Class Loader 소개​

  • 고도몰은 클래스의 FQN(Fully Qualified Name)을 이용해 class 파일을 자동으로 include 하는 autoload 시스템을 사용해요.
  • Classloader는 사용자 소스 디렉토리(User Source Directory) 안의 route.php에서 정의된 Class를 사용할 수 있도록 설정해요.
  • PHP에서는 Classloader를 Loader Stack에 여러 개 등록할 수 있고, Stack의 순서대로 Classloader가 동작해 Class를 찾아요. 하지만 고도몰에서는 하나의 Classloader만 사용하며, 내부에 여러 개의 ClassPathResolver를 등록해 Loader Stack을 구현하고 있어요.
Fully Qualified Name이란?

네임스페이스를 포함한 완전한 이름으로, Framework\ClassLoader\ClassLoader, Framework\Http\Request 같은 형태를 의미해요.

또한 네임스페이스와 물리적인 디렉토리 경로가 반드시 동일해야 Classloader가 정상적으로 실행돼요.

Class Loader 동작​

  1. Classloader가 사용자 소스 디렉토리(User Source Directory)의 module에서 class를 먼저 검색하고, 없으면 원본 소스 디렉토리(Base Source Directory)에서 검색해요.
  2. class가 사용자 소스 디렉토리(User Source Directory)의 module에서 검색되면 원본 소스 디렉토리(Base Source Directory)의 class는 무시돼요.
  3. 원본 소스 중 확장 가능한 class는 사용자 소스 디렉토리(User Source Directory)의 module에 원본 소스의 class를 확장한 Wrapping class를 만들어 사용할 수 있어요.

사용자 소스 디렉토리(User Source Directory) 구조​

  • 최상위 경로에서 동작하는 파일은 route.php, blank.php뿐이에요.
  • 신규 파일을 생성하려면 data, skin 디렉토리를 이용해 주세요.
  • tmp에서 이미지나 신규 파일 작업을 진행하면 파일이 소실될 우려가 있으니 지양해 주세요.

사용자 소스 디렉토리(User Source Directory) 권한​

  • data, skin 디렉토리(하위 경로 포함)는 0707 이상의 권한이 필요해요.
