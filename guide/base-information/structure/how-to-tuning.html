커스터마이징 진행 방법

커스터마이징 진행 개요​

고도몰의 커스터마이징은 원본소스 확인 → 소스 커스터마이징 → 운영환경 적용의 단계로 진행돼요.

1. 원본소스 확인​

고도몰의 원본 소스를 확인하는 단계예요.

원본소스 확인을 권장하는 이유는 커스터마이징이 가능한 범위를 직접 확인할 수 있을 뿐 아니라, 해당 소스를 기반으로 커스터마이징을 진행하시는 것을 권장하기 때문이에요.

고도몰 원본소스는 고도몰 상점 관리자의 '개발소스 관리'에서 확인할 수 있어요.

고도몰 원본소스에서 제공되고 있는 내용을 기반으로 기능을 추가하는 커스터마이징 예시

상품리스트 검색어 키워드에 '상품상태' 조건을 추가하는 커스터마이징

2. 소스 커스터마이징​

고도몰 원본소스를 기반으로 개발하는 내용으로 소스를 커스터마이징하는 단계, 즉 개발을 직접 진행하는 단계예요.

통상 소스 커스터마이징은 각 개발자(혹은 에이전시)의 로컬 환경에서 진행돼요.

3. 운영환경 적용​

개발(커스터마이징)한 소스를 운영환경에 적용하는 단계를 의미해요.

이는 곧 사용자들이 보는 쇼핑몰에 개발된 내용이 적용되는 것을 의미해요.

고도몰 커스터마이징 관련 제공 기능 '개발소스 관리' 소개​

고도몰의 기본 개발 방법은 원본소스를 확인하고, 커스터마이징하고자 하는 파일의 소스를 디렉토리로 복사하여 해당 파일에서 작업한 뒤 운영소스에 적용하는 것이에요.

앞서 말씀드린 것처럼 쇼핑몰 스킨패치를 제외한 모든 고도몰 패치는 자동으로 적용되는데요.

이를 위해서는 커스터마이징 시 아래 세 가지 사항을 반드시 준수해주셔야 해요.

자동패치 지원 대상이 되기 위한 필수 준수 사항
  1. 원본 소스의 class를 상속받을 것
  2. 원본 소스의 메소드 확장 개발 시, 반드시 원본 소스의 부모 메서드를 상속받을 것
  3. 다른 클래스를 사용하는 경우에는 namespace와 class 사이에 use를 이용하여 사용하려는 class를 추가할 것

고도몰이 제안하는 기본 개발방법대로 진행할 수 있도록 커스터마이징 관련 기능을 제공하고 있어요.

이 기능은 상점 관리자를 통해 접속 가능한 '개발소스 관리' 기능으로 사용하실 수 있어요.

해당 기능은 커스터마이징이 가능한 고도몰을 사용하시는 경우에만 노출되는 메뉴예요.

해당 기능이 확인되지 않는 고도몰은 커스터마이징이 불가한 상점이니 이용에 참고해주시기 바라요.
