홈개발가이드코딩 규칙

코딩 규칙

PHP Code Tags​

  • 반드시 <?php와 <?=만 사용해요.

php 파일을 template처럼 사용하는 경우, echo 태그는 가급적 <?=를 사용해요.

Closing Tag​

  • PHP 소스 코드만 포함된 경우 ?>를 생략해요.

Indenting​

  • TAB을 사용하지 않으며, 4자리 SPACE를 사용해요.
  • namespace, php open tag 레벨의 들여쓰기는 하지 않아요.

Control Structures​

Alternative syntax​

  • Alternative syntax를 사용하지 않아요.

Curly brackets​

  • {, } 사용 시 줄바꿈하지 않아요.

Indenting​

  • {, } 내부는 반드시 들여써요.

Control Statements​

  • Control Keyword와 조건문 사이에는 반드시 1개의 SPACE가 포함돼야 해요.
  • else if 대신 elseif를 사용해요.

Forbidden Functions​

  • sizeof 대신 count를 사용해요.
  • delete 대신 unset을 사용해요.
  • print 대신 echo를 사용해요.
  • is_null 대신 if ($var === null);을 사용해요.
  • create_function 대신 anonymous function을 사용해요.

Function Calls​

  • 메서드 또는 함수 호출 시 ->, (, ), ; 사이에 SPACE가 포함되면 안 돼요.
  • 각 Arguments 사이에 SPACE를 삽입해요.

Class Definitions​

  • 하나의 파일에는 하나의 클래스를 생성해야 해요.
  • {를 줄바꿈해요.
  • classloader에서 클래스 경로를 찾을 수 있도록 namespace를 정의해요.

Filenames​

  • 클래스명과 파일명이 일치해야 해요.
  • classloader에서 클래스를 찾을 수 있도록 namespace를 sub-directory로 간주한 위치에 파일을 저장해요.

Function Definitions​

  • 함수명과 (, ) 사이에 SPACE가 포함되면 안 돼요.
  • 클래스와 마찬가지로 {를 줄바꿈해요.

Arguments​

  • 각 Argument 사이에 SPACE를 넣어 가독성을 높여요.

Comments​

Inline Comment​

  • //만 사용해요.
  • #을 사용하지 않아요.

Block Comment​

  • 2줄 이상의 inline comment를 사용하지 않아요.

Document Comments​

  • 파일, 함수, 메소드, 프로퍼티, 클래스, 인터페이스에는 phpDocumentor 형식의 Document Comments를 작성해야 해요.
  • 구현 메소드의 Document Comments는 {@inheritDoc} 태그를 사용해요.

Task Tags​

  • @todo 키워드를 주석에 사용해 추가 작업 내용을 기록할 수 있어요.

TODO, FIXME, XXX는 사용하지 않아요.

File Formats​

  • BOM이 없는 UTF-8 인코딩을 사용해요.
  • 파일 인코딩을 혼용하지 않아요. (예: EUC-KR 환경에서 AJAX 처리를 위해 일부 파일을 UTF-8로 저장하는 행위)
  • 줄바꿈 문자는 Unix 타입의 LF만 사용해요.
  • 줄 끝 공백을 제거해요.
  • 파일 맨 마지막 라인에 빈 공백 라인을 추가해요.

Etc​

Operators​

  • 모든 연산자 앞뒤로 1개의 공백을 삽입해요.
  • Ternary Operator는 중첩 사용하지 않고, 중간 구문을 생략 사용하지 않아요.
  • Error Control Operators(@)를 사용하지 않아요.

Strings​

  • " 대신 '를 사용해요.
  • SQL문과 같이 내부에 '가 쓰일 수 있는 경우 " 사용을 허용해요.
  • Heredoc syntax를 사용하지 않아요.

Arrays​

  • 배열을 여러 줄로 정의할 경우 마지막 원소 끝에 ,를 추가해요.
  • 배열 선언 시 가급적 축약형 구문을 사용해요.
