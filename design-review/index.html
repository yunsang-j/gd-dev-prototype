디자인팀 검토 요청

개발자 센터 메인 화면을 아래 의도로 구성하고, 기획에서 NCDS 컴포넌트를 적용해 보았다. 이 구성과 형태가 맞는지 검토를 요청한다.

  1. 구성 의도 개발자 센터를 찾는 사용자는 쇼핑몰 운영자, 개발 담당, 유지보수 담당 세 부류다. 첫 화면에서 각자 자기 길을 바로 찾도록 역할 카드 3장을 두고, 같은 곳으로 가는 진입점은 한 번만 둔다. 상단 바와 히어로는 현재 운영 화면과 같은 패턴을 유지한다. "최초 기획 의도" 보기에서 확인할 수 있다.
  2. NCDS 적용 기획에서 역할 카드를 NCDS 블록으로, 역할 표기를 배지로, 가이드 보기 링크를 텍스트 버튼으로 바꿔 보았다. "NCDS 적용" 보기에서 확인할 수 있다. 역할 카드에 없는 목적지를 모은 "이럴 땐 여기로" 블록도 이 보기에 있다.
  3. 검토 요청 1 · 카드 구성 NCDS 를 적용한 카드 형태가 개발자 센터에 맞는지. 어드민 화면과 어느 정도 구분되어야 하는지.
  4. 검토 요청 2 · 역할 표기 카드마다 대상 사용자를 어떻게 표기할지. "NCDS 적용" 보기의 배지 위치·형태·색이 맞는지 봐 달라. 현재 적용한 색은 임시 값이다.
  5. 검토 요청 3 · 가이드 보기 링크 위치 본문 아래, 헤더 오른쪽, 링크 목록 마지막 줄 가운데 어디가 맞는지.
  6. 검토 요청 4 · "이럴 땐 여기로" 상황별 진입을 한 블록 안 목록으로 둔 형태와 문구 4개가 맞는지.
  7. 추가 요청 · 개발가이드 페이지 검토 담당자 지정 메인 외에 개발가이드 문서 페이지 전체(https://yunsang-j.github.io/gd-dev-prototype/guide/intro 이하)도 같은 관점의 검토가 필요하다. 검토를 맡아 주실 담당자 지정을 요청한다.
  8. 참고 프로토타입 https://yunsang-j.github.io/gd-dev-prototype/ · 현재 운영 화면 https://godomall-developers.github.io/
